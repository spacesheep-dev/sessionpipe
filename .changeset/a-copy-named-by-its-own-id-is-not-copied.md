A copy of a session is never itself copied, also when a message names it by its own id. A copy is on a receiver's board under its own id, and a message sent from there to a copy that was open in a window made a copy of the copy, where a message for the original was already told "a copy is never itself copied". The copy's own messages are now told the same: `unsupported`, "that copy was open in Claude Code on this computer (a terminal window or the Claude app), and a copy is never itself copied" (or what else holds it). An idle copy is resumed as before, and one in a turn or with an inbox that can be written to takes the message in place.
