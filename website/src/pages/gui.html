The control room for the agents you already run.

Every coding-agent session on your machines on one live board, and every one you ever ran a keystroke away. Answer, steer and start them from your laptop or your phone. No account, no cloud, no telemetry.

What it does

  • {{mark:board}}

    One live board

    Every session, grouped in the order you would look: needs you, working, stale, idle, done. One mark says the state, and only needs you gets the colour.

  • {{mark:chat}}

    Answer in place

    A session reads as a chat. Allow or deny the open prompt, send the next message, attach images, stop a turn.

  • {{mark:inbox}}

    One inbox

    Every open permission, question and error from every machine, newest first, with Allow and Deny on the ones a signed answer can reach.

  • {{mark:search}}

    Search all of it

    ⌘K across every session and this machine's own agent history, sessions from before sessionpipe included, in milliseconds, with the network down.

  • {{mark:plus}}

    Start a session anywhere

    Pick the machine, the agent and the folder. That machine's own sessionpipe starts it and checks everything again; the GUI runs nothing.

  • {{mark:key}}

    Signed by you

    Every command is signed by your passkey and checked on the machine that runs the agent. The GUI carries commands; it cannot forge one.

Desktop apps

A small app, on macOS and Linux.

The same UI in a Tauri 2 app on the system's own web view, not Electron. It connects to the receiver on this machine, and on first run it can start one for you as a service (that needs Node 20 or newer).

  • {{mark:bell}}A menu bar item and a Dock badge that count what needs you, and a notification when something does.
  • {{mark:fingerprint}}On a Mac it sends too: prompts, new sessions and permission answers, signed with a key in the Secure Enclave and unlocked with Touch ID.
  • {{mark:refresh}}It updates itself, and launches at login if you like.

On your phone

The same app at phone size: a tab bar, sheets, a two-line banner when something needs you. It is a page your computer serves, so there is nothing to install from a store.

  • {{mark:phone}}Scan the QR code sessionpipe-gui prints and the board is there; the key in the link signs the phone in.
  • {{mark:wifi}}Sending needs https and a passkey: the same Wi-Fi with the GUI's own certificate (--tls), or Tailscale from anywhere.
  • {{mark:home}}Add it to your home screen and it opens like an app.

A native iPhone build runs in the simulator; it isn't released yet.

{{phones}}

Or install it with npm

On any system with Node 20 or newer, Windows included. Then run npx sessionpipe install on each machine whose sessions you want on the board; search of this machine's own history works without it.

$npx github:spacesheep-dev/sessionpipe-gui

$npm i -g {{gui:tgz}}

The first tries it straight from GitHub; the second keeps sessionpipe-gui on your PATH. It runs on port 7373 and prints a QR code for your phone. No agent handy? sessionpipe-gui --demo fills the board with a synthetic team.
