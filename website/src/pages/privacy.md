# Legal & privacy

## Privacy notice for this website

*Dated 27 October 2026.*

- This site sets no cookies, runs no analytics, and loads nothing from third parties. Every page is static HTML with inline styles; the Content-Security-Policy on each page allows only this site's own scripts and forbids external requests.
- If you choose light or dark with the button in the header, the choice is kept in your browser's local storage so the next page opens the same way. It never leaves your browser; choosing your system's own scheme again removes it.
- It is hosted on GitHub Pages, whose servers log requests under [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
- The sessionpipe software sends data only to the sinks a person configures. The project operates no server that receives anyone's data.
- Questions: privacy@sessionpipe.org (until that address is live: a GitHub Discussion).
